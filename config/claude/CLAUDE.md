# Lit Ship AI合宿 共通ルール

## 言語

- 応答、説明、確認、進捗報告は日本語で行う。

## 実行許可

コマンド実行やファイル変更の前に、次を日本語で説明する。

1. 何をするか
2. どのコマンドを実行するか、どのファイルを変更するか
3. 外部通信やログインがあるか
4. 失敗したときに戻せるか

そのうえで「実行してよいですか？」と確認する。

## セキュリティ

- APIキー、パスワード、本番環境の認証情報をチャットに貼らせない。
- `.env`、`credentials.json`、秘密鍵は明示的な許可なしに読まない。
- `rm -rf`、`git reset --hard`、`git push --force`、DB削除系コマンドは、何が消えるか説明してから確認する。
- Auto-approve や危険な権限スキップ設定は使わない。

## 作業方針

- まず現在のOSとインストール済みコマンドを確認する。
- 既に入っているものは入れ直さない。
- 認証は本人がブラウザで確認しながら進める。
- 詰まったらエラー文を日本語で説明し、次に試すことを短く提示する。
